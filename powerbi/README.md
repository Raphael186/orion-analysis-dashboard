# Power BI

O PBIX original foi analisado para compreender a estrutura geral do relatório, mas não está neste repositório público. Arquivos PBIX podem conter modelo, consultas, dados importados, metadados e visuais com informação comercial ou pessoal.

A descrição das áreas do relatório está em [../docs/dashboard.md](../docs/dashboard.md). Para compartilhar uma versão executável, crie uma cópia sanitizada, substitua a fonte por dados autorizados, remova dados em cache e inspecione todas as páginas/visuais antes de publicar.
